# Hot Postgres, cold Iceberg on Citus

@use_case Development/UseCase/UC_Citus
@facet Store

Generated by `features/tiered.feature` (2026-10-17) against the on-demand cluster on Vultr: PostgreSQL 17.11, Citus 14.2-1, pgvector 0.8.7; a coordinator and two workers on a vc2-2c-4gb each, over a Vultr VPC (slice 2).

| Scenario | Result |
|---|---|
| An Iceberg table commits and rolls back with Postgres, its files on object storage | passed |
| Moving the old months to Iceberg changes no answer | passed |
| A move that fails leaves every row where it was | passed |
| A reader never sees an event twice or not at all while months move | passed |
| A late event for a month already in Iceberg goes to Iceberg | passed |
| The cold tier is open files: DuckDB reads it without Postgres | passed |
